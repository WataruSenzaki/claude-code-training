# L2 Unit: Skills — わけもわからず起動 → 種明かし

> L2 Bridge の第2 Unit。所属 Layer と全体像は [../README.md](../README.md)。
> 体験の核: **コマンド1つで起動 → 質問に答える → 自分の業務フローがファイルになる**。種明かしで「今のがスキル。何度でも呼べて、他の人にも配れる」。
> 軸: 「自分のものをCCに貯めて育てる」のうち "手順を貯める/任せる" 側。

## この Unit で生む「接続」
「決まった作業は技（スキル）にして呼び出せる・再利用できる・配れる」を体感させ、L3（自社業務用スキルを作る）への期待を作る。チャットと違い、**再利用できる道具**が手元に残るのが差。

## 構成（2つのスキル＋連鎖）
あえて2本に分け、初回は連鎖で1本の流れに見せる。

- **スキルA（入口）`/しごと棚卸し`**：応答ルール・プロフィール・今の業務（複数OK）を聞き、`CLAUDE.md` に追記。代表業務を1つ選ばせ、自動でスキルBを呼ぶ（連鎖）
- **スキルB（単独・再利用）`/業務フロー`**：代表業務1つの流れと付随作業を**徹底的に洗い出し**、`業務フロー.md` に書き出す。単独でも呼べるので、後日ほかの業務を整理したくなったらまた起動できる

初回の受講者は**スキルAを1つ打つだけ**。Aが連鎖でBを呼ぶので、体験は途切れない。

## 体験（視写・10〜15分）
1. `/しごと棚卸し` と打つ → スキルが質問を始める
2. 応答ルール・プロフィール・今の業務（複数OK）に答える
3. 代表業務を1つ選ぶ → 自動でスキルBに移り、その業務の流れと付随を深掘りする質問に答える
4. 終わると `CLAUDE.md`（応答ルール＋プロフィール追記）と `業務フロー.md`（代表業務の詳細フロー）ができている
5. 2つを開いて中身を見る

## 種明かし（ここで初めて説明）
- 「今のが**スキル**です。さっき手で1行書いたのと同じこと（記憶への書き込み）を、質問しながら自動でやってくれました」← 素手 Unit へのコールバック
- 「書かれた応答ルールは、**次回再起動後から振る舞いに効きます**（Unit 1 で見た通り）。気になる人は今すぐ再起動して確かめてOK」← 矛盾でなく復習として回収
- 「実は2つのスキルが連携していました（1つ目があなたを聞き、2つ目が業務フローを深掘り）」
- 「2つ目の `/業務フロー` は**単独でも呼べます**。別の業務を整理したくなったら、また打つだけ。**何度でも呼べて、他の人にも配れる**（横展開）」
- 「配れば、**誰の手元でも同じ手順が動く＝動作の再現性が保てる**。チャットの"うまくいった一回のやり取り"と違い、手順を技として固定して渡せるのが差」（再現できるのは"やり方"。出力が毎回一字一句同じになるわけではない、とだけ正確に）

## L3予告
「手元に "自分のこと"（CLAUDE.md）と "業務フロー"（業務フロー.md）がありますね。L3では、この業務フローを材料に、面倒な部分を片付ける**自分専用スキル**を作ってみます（完成は保証しないが、作る体験を持ち帰る）」

## 深掘りの方法（徹底的に・でもジャムらせない）
スキルBは受講者に長文を書かせない。**スキル側が候補を出して確認させる**：
- 例「試算表チェックなら、証憑突合・前月比較・摘要確認…といった作業はありますか？」→ はい/いいえ＋一言で答える
- 受講者が忘れていた付随作業をスキルが掘り起こす ＝「AIに明らかにしてもらう」体験そのもの。徹底性を保ちつつ自由入力のジャムを避ける

## 設計意図
- **なぜ2スキルに分けるか**：業務フロー深掘り（B）を単独で再利用できるようにするため。「スキル＝使い捨てでなく、何度でも呼べる道具」を体で示せる
- **なぜ連鎖させるか**：初回の受講者の操作を「1コマンド」に保つため。連鎖は自動なので追加操作なし
- **連鎖で通しで進めるため途中で再起動しない**：ここでの目的は「書かれて溜まる」を見せること。書いた応答ルールは次回再起動後から効く（Unit 1 の復習として種明かしで回収）。業務フロー.md は新規ファイルを開いて読むだけ

## 講師向け注意（ジャム対策）
- 唯一の自由入力＝質問への回答。スキル側を「候補提示 → はい/いいえ＋一言」に寄せ、完全自由記述にしない
- 20名×10〜15分。深掘りの質問数が時間を左右する。本番前に1人あたりの所要を実測し、Bの質問数を調整
- 連鎖が確実に動くこと・尺が収まることは本番前に実機で通す

## 流用元マッピング（実装は下流作業）
- `/profile`（応答ルール＋プロフィール＋連鎖）→ スキルA。業務リストアップを追加、会社プロフィール色を薄める
- `/scan`（連鎖先・深掘り）→ スキルB。深掘り対象を 競合/市場 から **業務フロー** に差し替え
- 出力先・尺（37分 → 10〜15分）は要改修

## 確認状況
- 設計確定：2スキル構成・連鎖・Bの単独再利用・出力2ファイル・深掘りはスキル主導
- 要確認（本番前）：スキル改修後の連鎖動作／1人あたり所要時間／受講者環境での起動
