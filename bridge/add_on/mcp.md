# MCP（外部ツール接続）— Add-on（標準外）

> L2 Bridge の標準外ユニット。所属層と全体像は [../../README.md](../../README.md)。
> 位置づけ: 標準講習には入れない。特定タイプ向け、または時間が余った時に紹介する材料。

## なぜ標準に入れないか
- MCP は Claude Code を外部サービス（Slack・データベース・社内ツール等）につなぐ仕組み。
- L2 共通の軸「自分のものをCCに貯めて育てる」（ローカルに残り次回も効く）に乗らない。接続先・認証が前提で、非エンジニアの初回には重い。
- だから本線（標準）から外し、Add-on（標準外）として保管する。

## 使いどころ（紹介する場合）
- すでに使っている外部サービスがある特定タイプ向け。
- 標準を終えて時間が余り「外ともつなげる」を見せたい時。
