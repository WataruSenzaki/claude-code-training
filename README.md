# Claude Code 研修教材（再考）— 目的とコンセプト

> 何を作っているかの忘れ防止メモ＆全体像。L1・L2 の中身は本ファイル（下記「各層の中身」）。L3 は [instances/](./instances/) で別管理。
> **なぜこの形か（設計の根拠）は [DESIGN.md](./DESIGN.md)。作り手との進め方は [CLAUDE.md](./CLAUDE.md)。**

## 大目的

何回やっても同じ結果になる、**再利用可能な研修教材の骨格**を作る。

- 対象: 非エンジニアの業務効率化希望者（特定イベント・特定受講者に依存しない汎用）
- 範囲: Claude Code の**インストール → 自社業務に使える**まで
- 背景: 過去に作って失敗した。場当たりでなく、エンジニア的に再現性・再利用性を持たせたい

## 設計の狙い

ターゲットが変わったときの**「変更ダメージ」を局所化**する。普遍の部分（L1・L2）と、対象ごとに差し替える部分（L3）を構造で分離する。

## 3層モデル（各層はゴールで定義。各語は1つの層だけを指す＝一意）

| 層 | ゴール | 中身 | 所属テスト |
|---|---|---|---|
| **L1 Bedrock** | 動く（install→PCで動かせる） | 導入／契約／セットアップ／基本操作 | 外したら"動く"に到達できないか |
| **L2 Bridge** | L1→L3 の橋渡し | CCのすごさを[説明＋体験]で持つプール（CLAUDE.md/Skills/MCP…） | 体験して"自分の仕事に使えそう"が生まれるか |
| **L3 Instance** | 自社業務につながる | タイプごとのインスタンス＝1目次（ハンズオン/振り返り/データ安全/例）。型＝L1/L2 に対する実体 | 層が選ぶ側。変更はここに閉じる |

- L2 は**順序なしのプール**、L3 が「このタイプにはどれを入れるか」を選ぶ。1タイプ＝1目次
- 各ユニットの中は **Mainline（外せない一本）＋ Add-on（肉付け）**。標準で教えるユニットは番号付き、標準外の Add-on は各層の `add_on/` へ
- 呼称: 層の中身は **ユニット**（旧「モジュール／Base Module／Option Module」は廃止）。**Bedrock は L1 を指す**。Option（データの安全等）は L3 の対象選択に吸収

## 各層の中身（L1・L2）

> L3 は対象タイプごとに L1＋L2 を選んで組む層（型＝L1/L2 に対する実体＝インスタンス）。独立フォルダで別管理 → [instances/](./instances/)。

### L1 Bedrock（動く）
順序あり（導入→契約→セットアップ→基本操作）。各ユニットは Mainline＋Add-on。標準は番号付き、標準外は `bedrock/add_on/`（必要時に作成）。

| # | ユニット | ねらい | 状態 |
|---|---|---|---|
| 1 | [導入](./bedrock/01_導入.md) | チャットAIとの3差分・完成品（L2成果物を静止で先見せ）・契約へ橋渡し | 確定（中身も） |
| 2 | [契約](./bedrock/02_契約.md) | Claude アカウント＋有料プラン（サブスク経路。API は add_on） | 確定（中身も） |
| 3 | [セットアップ](./bedrock/03_セットアップ.md) | install→応答（ゲート） | 確定（中身も） |
| 4 | [基本操作](./bedrock/04_基本操作.md) | 話しかけ→読ませ／直し→承認 ＋ 詰まっても自力復帰（自立） | 確定（中身も） |

### L2 Bridge（橋渡し）
順序なしのプール（番号＝汎用標準で教える順。L3 が選んで組み替えられる）。標準外は [bridge/add_on/](./bridge/add_on/)。
共通の軸＝**「自分のものをCCに貯めて育てる」**（情報＝CLAUDE.md／手順＝Skills。ローカルに残り次回も効くのがチャットとの差）。

| # | ユニット | 体験の核 | 状態 |
|---|---|---|---|
| 1 | [CLAUDE.md](./bridge/01_claudemd.md) | 1行を自分の手で書く→再起動→AIの振る舞いが変わる | 確定（素手版） |
| 2 | [Skills](./bridge/02_skills.md) | わけもわからず起動→種明かし「今のがスキル」→横展開できそう | 確定（2スキル＋連鎖） |
| add_on | [MCP](./bridge/add_on/mcp.md) | 外部サービスとつなぐ | 保留（標準外） |

- **非エンジニア汎用の通し（アーク）**: 1. CLAUDE.md を素手で1行 → 2. スキル起動（同じ書き込みを質問しながら自動で大量に・種明かしで(1)へコールバック）→ 3. L3予告（業務フローを材料に自社用スキル）
- **L2 の未定**: スキル本体の実装/改修（`/profile`→A・`/scan`→B、業務フロー寄せ・尺10〜15分への圧縮）／プールの拡充
