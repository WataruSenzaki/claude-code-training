# L3 Instance（自社業務につながる）

> 研修の Layer 構成の L3（最後の Layer）。ゴール＝**自社業務につながる**。タイプごとに L1 を通し＋L2 から選び＋自社業務に当てる。
> 全体像と他 Layer は [../README.md](../README.md)。
> 性質: **1 Instance ＝1目次**（Template＝L1/L2 に対する Instance）。対象が変わった時の変更ダメージはここにほぼ閉じる。

## この Layer が内部で取り扱うもの
- 自社業務ハンズオン（L1＋L2 を自分の仕事で実際に使う）
- 振り返り・持ち帰り（自社業務への橋渡し／次の一歩）
- データの安全／何を投げていいか（対象で選ぶ。守秘の重い対象＝会計士等で推奨）
- 横断判断: どの L2 Unit を入れるか／例の差し替え
