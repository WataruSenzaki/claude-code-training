Claude Code 研修

動く環境をつくる

導入

Claude Code とは

作業の代行者

Claude Code を一言でいうと——頼んだ作業を、代わりにやる
  • 調べる・読む・書く・直す…PC 上の作業を肩代わり
  • 人の手作業を、指示するだけで任せられる

チャットAIとの違い

チャットAI

聞けば 答える だけ

Claude Code

頼めば 代行する
たとえば——
  • 議事録を読んで、要点3つにまとめて保存
  • 30個のファイル名を一括で直す
  • 資料から数字を集めて1つの表に

本来はコーディング用

  • 正体は "コーディングエージェント" — もとは エンジニアの開発の道具
  • エンジニアが 手で書き換えていたファイルを、AI が代わりに直す

仕組みはファイルの読み書き

  • コードも書類（Excel・Word・PDF）も、結局 "PC の中のファイル"
  • ClaudeCode がやっているのは ファイルを読み、書き換えること
だから、その代行は コードに限らない。書類の仕事でもできる

仕事道具として広がりを見せている

これまで

エンジニアの 開発 の道具

いま

事務・資料・データの 仕事 へ
どんな仕事も中身は ファイル操作。だから他の仕事にも広がってきている

本講義の役割

この講座の目標

  • 出回っている機能の一端を、まず体験する
  • ClaudeCode を通して、自分の動く環境・ルール・業務のまとめを作る
手元に残る成果物
  • CLAUDE.md … 自分のルール
  • 業務.md … 仕事のまとめ（手間と判断）

そこまでの道のり

1 動く … 環境を作る

2 育てる … 自分用に

3 つかう … 自分の仕事で

まず、動く環境をつくる

必要なのは 3つ。携帯にたとえると——

要素携帯でいうと
契約サービス契約（サブスク）
インストール端末を手に入れる
認証その端末を契約者が使う紐付け
流れは 契約 → インストール → 認証。まず契約から

契約

契約のステップ

1 アカウントを作る

2 有料プランを契約する

3 有効か確認する

1. アカウントを作る

  • claude.com でサインアップ（メール／Google など）
  • すでにアカウントがあれば、それでOK
これが ログインの前提になる

2. 有料プランを契約する

無料プランでは使えない。有料プランが必須
  • claude.com で 有料プランを契約
  • どのプランかは 研修側の案内どおり

3. 有効か確認する

ここが仕上がりチェック（ゲート）

  • claude.com で 有料プランが有効と表示
見えていれば、次の セットアップでログインが通る

できたら次へ

手に入ったもの
  • 有効なアカウント（有料プラン）
  • その ログイン情報
次は セットアップ＝携帯でいう「端末を手に入れる」

セットアップ

セットアップのステップ

1 インストールする

2 パスを通す

3 起動する

4 ログインする

5 応答を確認する

1. インストールする

ターミナル（黒い画面）を開いて、下の1行を貼るだけ。

OSコマンド
Macターミナル（Terminal.app）で curl -fsSL https://claude.ai/install.sh | bash
WindowsPowerShell で irm https://claude.ai/install.ps1 | iex

2. パスを通す

端末を開き直して claude --version。バージョンが返れば次へ。

返らない＝claude の場所が未設定（PATH）。多くは端末を開き直すだけで直る

それでも返らないとき＝下の1行を貼る

OSPATH を通す
Mac / Linuxecho 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc（bash は ~/.bashrc）→ 開き直す
Windows$p=[Environment]::GetEnvironmentVariable('PATH','User'); [Environment]::SetEnvironmentVariable('PATH',"$p;$env:USERPROFILE\.local\bin",'User') → 新しい端末

3. 起動する

claude と打つだけ（Mac・Windows 共通）。

claude

4. ログインする

初回起動で自動的にログインを促される。

  • ブラウザが開く
  • 契約したアカウントでサインイン
  • 端末に戻る
サインインは 契約のアカウントで

5. 応答を確認する

ここが仕上がりチェック

何か打ってみる。例「こんにちは、何ができますか？」

  • 打ったら応答が返ってくる
返れば、自分のPCで Claude Code が動いている

できたら次へ

手に入ったもの
  • 自分のPCで打てば Claude Code が応答する状態
次は 基本操作＝話しかけて、ファイルを読ませ・直す

基本操作

基本操作のステップ

1 どこで動かす

2 話しかける

3 ファイルを読ませる・直してもらう

4 承認する

5 詰まったら自分で戻る

1. どこで動かす

  • Claude は 起動したフォルダを基準点にして動く（そこのファイルを読み書きする）
  • 基準点は自動＝働きたい場所で起動するだけ（フォルダ指定は要らない）
今回は デスクトップで起動＝デスクトップが基準点。自分のファイルが見えて分かりやすい

2. 話しかける

やってほしいことを、日本語でそのまま打つ。

例「このフォルダに何があるか教えて」
命令の呪文は要らない

3. ファイルを読ませる・直してもらう

ファイル名（パス）を渡して読ませ、直した結果を確認する。

例「議事録.txt を読んで要点を3つに」→「清書版を 議事録_清書.txt に保存して」
これが チャットとの違い＝手を動かす

4. 承認する

  • 変更の前に 「これ変えていい？」と必ず聞かれる
  • 許可するまで 何も変わらない
見て 許可／やめてを選ぶ＝勝手に壊されない

5. 詰まったら自分で戻る

困ったら、この3つで戻れる。

操作何が起きる
Esc止める（途中で中断。やった分は残る）
/clear仕切り直し（新しい会話。前の会話は保存され、後で再開できる）
Ctrl+C を2回終了 → claude で再起動
この3つで いつでも戻れる

できたら次へ

手に入ったもの
  • 一人で一周まわせる
  • 詰まっても自力で戻れる
ここで 動く環境は完成。次は自分用に 育てる

自分用に育てる

このパートでやること

1 動く … 環境を作る（できた）

2 育てる … 自分用に（いま）

3 つかう … 自分の仕事で

このパートで「自分のもの」を ClaudeCode に 2つ貯める——

  • 決まった手順（スキル）

CLAUDE.md

CLAUDE.md とは

振る舞いの指示書

CLAUDE.md を一言でいうと——ClaudeCode の振る舞いを決める、自分で書く指示書
  • ClaudeCode が起動するたび、必ず読む
  • 書いておくと、ClaudeCode の振る舞いがそれに沿う
  • 書くのは——呼び方・口調・進め方など、自分好みの振る舞い（自己紹介ではない）

なぜ毎回効くのか

  • ClaudeCode は起動するたび、前回の会話を忘れている（毎回まっさら）
  • でも CLAUDE.md は、起動時に読み直す＝記憶になる

だから一度書けば、次からずっと効く

「楽にする入口」に手を付けるとき——入口には2種類ある。
