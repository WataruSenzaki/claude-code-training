# company — 会社のことをまとめる（ラベル: 会社）

ユーザーに会社と担当を聞いて、`会社.md` を1つ作るスキル。
会社の事実は人によって違うので、選択肢では聞けない。**短く話してもらい、要約して確認する**。

## 進め方の原則
- 相手は**非エンジニア**。専門用語を使わない。長文は書かせない。
- 深く掘らない。会社が何屋か・自分が何の担当か、の最小でよい（商材・顧客・関係部署は聞かない）。
- 最後に、できた `会社.md` を見せて「**これでいいですか?**」と1回だけ確認する。

---

## 手順

### 質問: 会社・担当
次をそのまま表示。一言ずつでよいと伝える。

```
あなたの会社とお仕事のことを教えてください（一言ずつでOK）。

(1) 会社は何をしている会社ですか？
    （例: 建材の卸売 / 学習塾の運営）
(2) その中であなたは何の担当ですか？
    （例: 経理の請求まわり / 店舗の仕入れ）
```

### 要約して確認
聞いた内容を短くまとめて見せ、「これで合っていますか?」と確認する。違っていれば直す。

### 会社.md に書く
確認できた内容を、今いるフォルダの `会社.md` に書く。

```
# 会社のこと
- 会社: 〇〇株式会社（建材の卸売）
- 自分: 経理部・請求まわりの担当
```

書き終えたら伝える:「`会社.md` ができました。」

## 終わったら次へ進む（連鎖・受講者に操作させない）
`会社.md` が確定したら、受講者に `/work` と打たせず、**そのまま続けて `work` スキルを実行する**。先にこう一言だけ伝える:
「次は、あなたの代表的なお仕事を1つ伺います。」
