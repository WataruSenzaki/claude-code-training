# profile — 自分用の設定をつくる（ラベル: プロフィール）

ユーザーに質問して、答えから **自分好みの振る舞い** を `CLAUDE.md`（振る舞いのルール）に書くスキル。

> このスキルが入口。終わると 会社（company）→ 業務（work）→ 可視化（draw）へ**自動で続く**（受講者は最初に1回だけ起動）。各スキルは単独でも呼べる。

## 進め方の原則
- 相手は**非エンジニア**。専門用語を使わない。長文は書かせない。
- 選択は **AskUserQuestion ツールで選んでもらう**（呼び方だけは自由入力の普通の質問）。AskUserQuestion は「その他」を自動で用意するので、候補に無い答えも自由入力で受けられる。出てきた「その他」もそのまま採用する。
- 迷っていたら例を足して助ける。
- 最後に、できた `CLAUDE.md` を見せて「**これでいいですか?**」と1回だけ確認する。

---

## 質問1: 呼び方（普通の質問・自由入力）
次をそのまま表示して、答えを待つ。

```
あなたを何とお呼びすればいいですか？
（例: 田中さん / たなやん / 名前そのまま）
```

## 質問2〜4: 口調・説明・進め方（AskUserQuestion で選んでもらう）
**AskUserQuestion ツール**で次の3問を聞く（1回の呼び出しにまとめてよい）。どの質問も「その他」で自由入力を選べる（AskUserQuestion が自動で用意。出てきた自由入力もそのまま採用する）。

- **口調**（1つだけ選ぶ）
  - 敬語でていねいに
  - フレンドリーにくだけて
- **説明の出し方**（複数選択可＝multiSelect）
  - 結論から先に言う
  - 専門用語は避けて、かみくだいて説明する
  - なるべく短く、簡潔に
- **進め方・安全**（複数選択可＝multiSelect）
  - 作る・変える前に「これをします」と一言確認してから動く
  - ファイルを消す・大きく変える時は必ず確認する
  - 勝手に直さず、まず案を出して選んでもらう

## CLAUDE.md に書く
呼び方・選ばれた項目（「その他」の自由入力も含む）を**事実形式の箇条書き**にして、今いるフォルダ（自分用フォルダ）の `CLAUDE.md` に書く。
選ばれた項目だけを並べる。例:

```
- ユーザーを「田中さん」と呼ぶ
- 敬語でていねいに話す
- 結論から先に伝える
- 専門用語は避け、かみくだいて説明する
- 作業の前に「何をするか」を一言確認してから動く
- ファイルを削除・大きく変更する前に必ず確認する
```

## 最後の確認
できた `CLAUDE.md` を画面に見せ、「これでいいですか? 直したいところがあれば教えてください」と聞く。
直しの希望があれば、該当する行だけを直す。

## 終わったら次へ進む（連鎖・受講者に操作させない）
このスキルは入口。CLAUDE.md が確定したら、受講者に `/company` と打たせず、**そのまま続けて `company` スキルを実行する**（＝会社の質問を始める）。先にこう一言だけ伝える:
「ありがとうございます。続けて、会社のことを少しだけ伺います。」
